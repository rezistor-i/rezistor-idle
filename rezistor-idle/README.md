# Мастерская «Резистор»: Империя Ремонта

Idle-игра о развитии мастерской по ремонту ПК. Один HTML-файл, работает офлайн,
сохраняет прогресс в localStorage.

## Локальный запуск
Просто откройте `index.html` в браузере.

## Музыка
Положите MP3 в `assets/audio/workshop-theme.mp3` — трек подхватится автоматически.
Без файла игра работает, но кнопка музыки скрыта.

## Публикация
Развёрнуто на Cloudflare Pages (статический хостинг).
